Decidí usar Node.js con Express porque es una forma sencilla de crear una API y me permite organizar bien el código.Separé el proyecto en archivos para tener todo más ordenado: uno para el servidor y otro para las rutas de las tareas.

Las tareas las guardo en memoria, sin base de datos, para que sea más fácil de probar en Postman. Cada tarea tiene un título, una descripción, un estado y una fecha límite. Con eso puedo crear, ver, actualizar o eliminar tareas, y también filtrarlas según su estado.
